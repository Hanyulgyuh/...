# Infinite Dungeon Train

**Infinite Dungeon Train**은 끝없이 이어지는 던전 열차를 배경으로 한 싱글 플레이 로그라이크 실시간 액션 RPG입니다.
플레이어는 무한히 생성되는 열차 칸을 지나며 전투, 보상, 성장, 분위기 변화를 반복하고, “이번 칸만 더 가보자”라는 감정을 계속 느끼도록 설계됩니다.

## 핵심 키워드

- 로그라이크 RPG
- 실시간 액션
- 무한 성장형 던전
- 랜덤 열차 칸 생성
- 중독성 있는 반복 플레이
- 현실 도피와 심리적 붕괴 분위기
